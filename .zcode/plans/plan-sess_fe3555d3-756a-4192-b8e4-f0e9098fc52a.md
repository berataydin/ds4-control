# Max output tokens + chat parameters in Settings

## Context

Kullanıcı, Max Think modunda kapsamlı bir soru sonrası üretimin ~32K token'da aniden durduğunu bildirdi. Kök neden: `ChatService.makeRequest` içinde `"max_tokens": 32768` sabit kodlanmış (`Sources/DS4Control/Services/ChatService.swift:66`) ve Settings'te değiştirilemiyor. Model yükleme parametreleri (ctx, port, host, paralel oturumlar, GPU power, disk KV) zaten Settings ▸ Server'da; eksik olan sohbet istek parametreleri. Bu değişiklik **max output tokens** (varsayılan **65.536** — kullanıcı onayı) ve **temperature** (varsayılan 0.7) ayarlarını Settings ▸ Chat bölümüne ekler; değerler AppState'e kalıcı yazılır ve yerleşik sohbet tarafından canlı okunur (yeniden başlatma gerekmez, bir sonraki mesajdan itibaren geçerli olur). Kodlama ajanları (pi/claude) kendi limitlerini kendileri belirler — ajan yolu (AgentLauncher) değişmez.

## Changes

### 1. `Sources/DS4Control/Services/ChatService.swift`
- Yeni sabitler: `static let defaultMaxTokens = 65_536`, `static let defaultTemperature = 0.7` (tek doğruluk kaynağı; AppState ve Settings bunlara referans verir).
- `stream(...)` ve `makeRequest(...)` imzalarına `maxTokens: Int = ChatService.defaultMaxTokens, temperature: Double = ChatService.defaultTemperature` parametreleri eklenir; gövde `"max_tokens": maxTokens, "temperature": temperature` kullanır. Mevcut testler varsayılan parametrelerle derlenmeye devam eder.

### 2. `Sources/DS4Control/AppState.swift`
- Mevcut `@Published var X { didSet { d.set(...) } }` desenine uyan iki tercih (init'te geri okuma ile):
  - `maxOutputTokens: Int` — key `"maxOutputTokens"`, default `ChatService.defaultMaxTokens`; yüklerken `1_024...1_048_576` aralığına kenetlenir (1.048.576 = V4.1 ctxCeiling, en büyük tavan).
  - `chatTemperature: Double` — key `"chatTemperature"`, default `ChatService.defaultTemperature`; yüklerken `0...2` aralığına kenetlenir.
- Göç gerekmez: anahtar hiç saklanmamışsa yeni kullanıcı davranışı gibi 65.536 okunur.

### 3. `Sources/DS4Control/DS4ControlApp.swift`
- Chat `streamProvider` closure'ı (mevcut `mode: app.thinkingMode` deseninin yanına) `maxTokens: app.maxOutputTokens, temperature: app.chatTemperature` okur — closure `app` referansını canlı tuttuğu için değer değişikliği yeniden başlatma olmadan bir sonraki mesaja uygulanır.

### 4. `Sources/DS4Control/Views/SettingsView.swift`
"Chat" bölümüne (ThinkingModePicker'ın yanına):
- **"Max output tokens"** — `ctxText` deseninde TextField binding (sadece rakam filtresi; boşaltılırsa default'a döner; 1.024–1.048.576 kenetlemesi). Altına caption: varsayılan 65.536; Max Think uzun cevapları 32K'yı aşabilir, cevap erken durursa yükseltin; yerleşik sohbet için geçerlidir, kodlama ajanları kendi limitini belirler.
- **"Temperature"** — `powerBinding` deseninde Slider (0–2, adım 0.05) + canlı sayısal değer. Caption: varsayılan 0.7.
- Bölüm footer'ı (mevcut `thinkingHint`) yeni satırları kapsayacak şekilde güncellenir ("defaults: 65,536 tokens / 0.7"; anında geçerli).

### 5. Tests
- `Tests/DS4ControlTests/ChatServiceTests.swift`: `testRequestBodyShape` içindeki `max_tokens == 32768`断言 65_536'ya güncellenir; yeni test: özel `maxTokens`/`temperature` değerlerinin JSON gövdeye düştüğünü doğrular.
- `Tests/DS4ControlTests/AppStateTests.swift` (mevcut `UserDefaults(suiteName:)` deseni): default'lar (65.536 / 0.7), kalıcılık round-trip, ve yükleme-time kenetleme (100→1024, 5.000.000→1.048.576; sıcaklık 5→2, -1→0) testleri.

### 6. `AGENTS.md`
- AppState tercihleri parantez listesine `maxOutputTokens, chatTemperature` eklenir (dosyanın State satırı).
